Electrical Impedance Spectroscopy for Bioimpedance Imaging Applications

Features

This project proposes an imaging system for melanoma detection using EIS. We have achieved the following with our design:

  • A more convenient, portable sensor design
  • Affordability
  • Non-invasiveness

Components

Impedance Sensing Subsystem

  • AD5933 Evaluation Board
  • Coax RG-174 (Shielded Wire)
  • OPA376 Guard Op Amp
  • CD4053BE Multiplexer (2:1)

Motor Subsystem

  • A4988 Motor Driver
  • 1.8° Nema 17 Stepper Motor

Additional Components

  • Arduino Uno Board with Bluetooth Module
  • Laptop/PC




ABOUT

Our Bio-impedance-Sensing Device

Purpose

As a widespread and often deadly cancer, skin cancer demands more accessible and accurate early diagnostic tools.

Early detection is critical, yet current diagnostic methods rely primarily on visual inspection and invasive biopsies, which are costly, uncomfortable, and inaccessible to many.

This project proposes a non-invasive imaging system for melanoma detection using EIS — Electrical Impedance Spectroscopy.
